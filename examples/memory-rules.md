# memory rules · м.

обновлено: 2026-06-10 · артефакт d4 · gate: local · агент читает перед ЛЮБЫМ сохранением

## хранить свободно (local)

- цели, ппр, трекинг движения, метрики практик
- журнал решений: контекст, варианты, ожидания, исходы
- инсайты недели в общем виде («заметил откладывание после звонков о деньгах»)
- рабочие предпочтения: как мне отвечать, что раздражает

## спрашивать перед сохранением (ask_first)

- всё, где упоминается часть из parts-map по имени
- выводы агента о моих паттернах (гипотеза ≠ факт; сохраняем только подтверждённое мной)
- цитаты из дневника, даже вставленные мной

## никогда (do_not_store)

- материал терапевтических сессий дословно
- что-либо о третьих лицах кроме инициалов и рабочих договорённостей
- медицинское, диагнозы, лекарства
- содержимое чужих сообщений мне

## форма записи

одна запись = одна строка в индексе + файл-карточка при необходимости. каждая запись с датой. раз в месяц — чистка: что устарело, удалить; что выросло — перенести в about-me.

## право на забывание

по команде «забудь это» запись удаляется без вопросов и без следа в логе.
