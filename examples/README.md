# examples · возможный результат

полный пример контура, собранного по `harness-setup-selfdev` за один вечер + первую неделю.

## история «м.»

м. — продакт-лид в b2b-стартапе, кофаундер-партнёрство 4-й год. практика: терапия (ifs-ориентированная) раз в две недели, утренние страницы ~4 раза в неделю, два випассана-ретрита. на спринт пришёл с двумя запросами: перегруз зависшими решениями и один трудный разговор с кофаундером, который откладывался месяцами. за вечер сетапа собрал контур из 5 файлов и 3 скиллов; через неделю контур производил данные, на которые можно опереться.

## как использовать

читать сверху вниз как историю одного сетапа — либо открыть файл нужной стадии рядом со своим и сверить форму. копировать не сами тексты, а форму: способ действовать у каждого свой.

## выдержки · форма без открытия файлов

**из [CLAUDE.md](CLAUDE.md) — точка входа контура м.:**

```
## границы — никогда без подтверждения
- ничего не отправлять наружу: ни сообщений, ни писем, ни публикаций
- содержимое parts-map и материал терапии: не цитировать, не пересказывать,
  не включать в сводки; при сомнении — спросить
- третьи лица (кофаундер, семья): только инициалы, деталей не хранить
- не ставить диагнозы; «похоже на часть, которая…» — допустимо, ярлыки — нет
```

**из [decision-rails.md](decision-rails.md) — рельс №1:**

```
рельс 1 · разговор с кофаундером о зонах
- обратимость: разговор обратим; молчание — накапливает необратимое
- варианты: письмо как подготовка → разговор · фасилитатор · ничего (названо явно)
- if-then: если ловлю смягчение — читаю вслух заранее записанную фразу-якорь
- review: 2026-06-20 · статус: открыт · скилл: conversation-prep
```

**из [memory-rules.md](memory-rules.md) — три правила:**

```
хранить свободно: цели, ппр, трекинг, журнал решений, инсайты в общем виде
спрашивать перед сохранением: всё, где упоминается часть из parts-map по имени;
  выводы агента о паттернах (гипотеза ≠ факт)
никогда: материал терапевтических сессий дословно · третьи лица кроме инициалов
```

**из [week-1-log.md](week-1-log.md) — строка трекинга:**

```
| разговор с кофаундером | состоялся до 06-20 | ◐ | письмо отправлено;
  разговор назначен на вт | 7/10 |
паттерн: бросаю всё бездатное — 3 закрытых решения, все с ревью-датой
```

## как это связано с конфигуратором

[apowall.github.io/harness-setup-selfdev](https://apowall.github.io/harness-setup-selfdev) — интерактивная страница: выбираешь блоки контура и линзы практики, получаешь один промпт. промпт ссылается на `SKILL.md` этого репозитория — агент читает методику сам и ведёт по блокам, по одному, оставляя за собой артефакты. форма этих артефактов — именно то, что ты видишь в папке `examples/`: синтетический участник «м.» от discovery до лога первой недели.

## naming convention в действии

пять примеров следов, которые оставил бы м. в течение недели:

| имя файла | жанр |
|-----------|------|
| `selfdev {prep} разговор с к. – 2026-06-13.md` | подготовка к трудному разговору |
| `selfdev {debrief} после терапии – 2026-06-17.md` | разбор после сессии |
| `selfdev {review} неделя 24 – 2026-06-15.md` | недельный обзор |
| `selfdev {decision} переезд – 2026-06-10.md` | зафиксированное решение |
| `selfdev {insight} решения без даты зависают – 2026-06-15.md` | одна находка недели |

постоянные файлы (`about-me.md`, `memory-rules.md`, `decision-rails.md`, `insight_index.md`) живут без даты — они обновляются на месте, дата только у следов-событий.
