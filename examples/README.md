# examples · возможный результат

полный пример контура, собранного по `harness-setup-selfdev` за один вечер + первую неделю. участник синтетический: «м.», продакт-лид, практика — терапия (ifs) раз в две недели + утренние страницы + випассана-ретриты. запрос спринта: перегруз решениями и отложенный трудный разговор с кофаундером. совпадения с реальными людьми случайны; все цифры и цитаты выдуманы.

## что здесь лежит и из какой стадии берётся

| файл | стадия | что показывает |
|------|--------|----------------|
| `harness-discovery.md` | 1 · discovery | портрет практики, 6 ai-задач, 3 кандидата в скиллы, карта границ, 3 линзы из библиотеки |
| `harness-inventory.md` | 2 · инвентарь | gap-таблица по 7 слоям — что было, чего не хватало |
| `CLAUDE.md` | 3 · точка входа | тощий файл 52 строки с permissions-блоком |
| `about-me.md` | D4 → слой context | ппр с горизонтами 1/3/10 |
| `memory-rules.md` | D4 → слой память | что хранить / спрашивать / никогда |
| `decision-rails.md` | D4 → слой evidence | два рельса с woop и датами ревью |
| `skills/track-my-selfdev/` | 4 · скилл 1 | еженедельный трекинг ппр |
| `skills/weekly-reflect/` | 4 · скилл 2 | разбор недели по следам |
| `skills/conversation-prep/` | 4 · скилл 3 | подготовка трудного разговора (d8) |
| `week-1-log.md` | 5 · после недели | реальный выход: лог трекинга + выжимка session inspector lite |

## как использовать

читать сверху вниз как историю одного сетапа — либо открыть файл нужной стадии рядом со своим и сверить форму. копировать не сами тексты, а форму: способ действовать у каждого свой.
