# weekly reflect

разбор недели по следам, линза transcript mining: следы вместо воспоминаний. owner: м.

## когда использовать
раз в неделю после track-my-selfdev; вход — всё, что я вставлю: фрагменты страниц, заметки, выжимка session inspector.

## когда НЕ использовать
в остром состоянии (это инструмент обзора, не поддержки — в остром состоянии терапия и люди); без следов («по памяти» даёт пересказ настроения, не разбор).

## шаги
1. принять следы недели: вставленные фрагменты + `selfdev/insight_index.md` + просроченные ревью из decision-rails
2. структура: события → повторы → один паттерн недели (гипотезой, не вердиктом)
3. сверка с картой частей ТОЛЬКО как вопрос: «похоже на [имя части]? — да/нет/не знаю», без цитирования parts-map
4. один вопрос себе на неделю (записать, не отвечать)
5. одна строка в `selfdev/insight_index.md`: дата · паттерн · источник следа

## формат
```markdown
## неделя YYYY-MM-DD
события: 3–5 строк
повтор: …
паттерн (гипотеза): …
вопрос недели: …
```

## типовые ошибки
- больше одного паттерна за раз — размывает; один, зато с следом-основанием
- интерпретация частей вместо вопроса — граница из CLAUDE.md
- разбор >20 минут — признак, что вход не подготовлен (следы не собраны заранее)
