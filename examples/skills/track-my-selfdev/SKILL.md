# track my selfdev

еженедельный трекинг движения по ппр из `selfdev/about-me.md`. owner: м. (агент готовит, я подтверждаю).

## когда использовать
воскресенье, в связке с weekly-reflect; или точечно — «зафиксируй прогресс по [цель]».

## когда НЕ использовать
для постановки новых целей (это правка about-me.md руками) и для терапевтического материала (gate: см. memory-rules.md).

## шаги
1. прочитать таблицу ппр из `selfdev/about-me.md` и прошлую запись в `selfdev/track_my_selfdev.md`
2. собрать следы недели: insight_index, журнал решений (просроченные ревью!), фрагменты, которые я вставил
3. по каждой цели — статус по метрике: ✓ движется / ◐ частично / ✗ стояла, с одним фактом-основанием
4. спросить меня самооценку по каждой цели 1–10, коротко (≤5 пунктов)
5. одна строка «фокус следующей недели» — предложить, я подтверждаю
6. дописать блок в `track_my_selfdev.md`, формат ниже

## формат записи
```markdown
## review · YYYY-MM-DD
| цель | метрика | статус | факт | самооценка |
|------|---------|--------|------|------------|
фокус недели: …
```

## типовые ошибки
- статус без факта-основания («кажется, двигалось») — не писать
- превращать разбор в коучинг: это трекинг, 10 минут, не сессия
- трогать формулировки целей — цели меняются только в about-me.md руками
