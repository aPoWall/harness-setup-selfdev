# conversation prep

подготовка разговора, который важно не смазать. формат с воркшопа d8. owner: м.

## когда использовать
за 1–2 дня до разговора с реальной ставкой: зоны с кофаундером, деньги, границы, семья.

## когда НЕ использовать
для рутинных синков (перегрев инструмента обесценивает его) и вместо самого разговора (подготовка ≠ разговор; готовый prep без назначенной даты — прокрастинация в красивой форме).

## шаги
1. собрать контекст: договорённости и история по человеку (инициалы! см. memory-rules), мой рельс из decision-rails если есть
2. желаемый исход одной фразой: что должно стать другим после разговора
3. повестка ≤3 пунктов; трудное — первым (после 20-й минуты его не поднимут)
4. риски: что сделает «дипломат» в моменте (смягчение, шутка, перенос темы) — по одному if-then на каждый
5. фраза-якорь: записанная заранее формулировка трудного, дословно
6. после разговора — debrief 5 минут: что сказал / что смягчил / что перенёс; строка в decision-rails

## формат
```markdown
# prep · [инициалы] · YYYY-MM-DD
исход: …
повестка: 1. (трудное) 2. 3.
риски → if-then: …
якорь: «…»
---
debrief: …
```

## типовые ошибки
- досье из чужих слов и сплетен — только мои факты и договорённости
- повестка из 7 пунктов — это другая встреча
- prep без даты разговора в календаре — вернуть в decision-rails как открытое решение
